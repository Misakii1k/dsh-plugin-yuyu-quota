鱼鱼 API 资产监控插件 · 新手使用教程

纯原生本地无感直连 · 多账号秒切 · 智能频率调谐

第一步：浏览器正常登录 免输入 Token
在 Chrome 或 Edge 浏览器中登录鱼鱼 API 控制台（sub.anzhiyu.com/usage）。插件会自动只读扫描本地存储提取有效 Token，无需手动复制黏贴。
第二步：卡片内多账号 0 延迟秒切 多账号共存
卡片右上角横向罗列已登录账号（如不同账号前缀胶囊）。轻点对应胶囊即可无感秒切，可用余额、今日实扣与名下密钥一并即时同步展示。
第三步：刷新频率灵活调节 最低 1 秒实时刷新
点击顶栏齿轮设置按钮，可按需切换 1秒 / 5秒 / 30秒 / 1分 / 5分。具备智能防封保护：卡片展开时按设定高速刷新，收起时自动降频静默。
在 DeepSeek Harness 客户端窗口中按快捷键刷新：
Ctrl + R
前往鱼鱼控制台
