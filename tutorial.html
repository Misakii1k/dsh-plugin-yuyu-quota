鱼鱼 API 资产监控插件

使用指南

纯原生本地无感直连 · 浏览器凭据自动扫描 · 多账号毫秒级秒切

01
浏览器正常登录 免输入 Token
在 Chrome 或 Edge 浏览器中登录鱼鱼 API 控制台（sub.anzhiyu.com/usage）。插件会自动只读扫描本地存储提取有效凭据，无需繁琐复制黏贴。
02
卡片内多账号秒切 多账号共存
拥有多个账号时，卡片右上角横向罗列前缀标签。轻点对应标签即可无感秒切，可用余额、今日实扣与名下密钥一并即时同步展示。
03
刷新频率与节拍调谐 最低 1 秒实时刷新
点击顶栏齿轮设置按钮，可按需切换 1秒 / 5秒 / 30秒 / 1分 / 5分。具备智能防封保护：卡片展开时按设定高速刷新，收起时自动降频静默。
在 DeepSeek Harness 客户端窗口中按快捷键刷新：
Ctrl + R
前往鱼鱼控制台
