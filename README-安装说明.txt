======================================================================
     鱼鱼API (sub.anzhiyu.com) 资产监控插件 - DSH 极速安装包 v1.0.9
======================================================================

【特点】
- 零配置：自动读取本机 Chrome/Edge 浏览器已登录的鱼鱼账号，无需输入复杂 Token；
- 零依赖：纯原生极速扫描，默认不使用 MCP；
- 多账号：支持名下多个鱼鱼账号一键秒切；
- 频率调节：支持 1秒实时/5秒/30秒/1分/5分 频率切换，具备收起后台智能防封调度；
- Token格式化：自动以 K/M 紧凑展示，悬停可查看精确值；
- 动效新手教程：安装后自动弹出独立纯原生 SVG 动效使用向导；
- Oil UI 灵动设计：原生 1.8px 细线条矢量 SVG（无 Emoji），丝滑抽屉折展与物理微阻尼。

----------------------------------------------------------------------
【安装方式一：人类朋友极速安装（推荐，最省事）】
----------------------------------------------------------------------
1. 解压本压缩包到任意文件夹（例如桌面）；
2. 鼠标双击运行 【一键安装到DSH.bat】；
3. 打开或切换到 DeepSeek Harness，按键盘 【Ctrl + R】 刷新，右下角即会显示鱼鱼资产胶囊！

----------------------------------------------------------------------
【安装方式二：交给 AI Agent 安装】
----------------------------------------------------------------------
1. 把解压后的文件夹发给你的 AI 助手；
2. 直接复制并发送 【发给Agent的安装指令.txt】 里的提示词；
3. Agent 5秒内即可自动配置完成。
