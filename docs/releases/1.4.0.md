# v1.4.0

新增新站人民币折算与更广的浏览器登录态扫描，并重做余额卡片的币种交互。

## 新站人民币折算

- 新站读取 `/api/v1/currency/rates` 的 `USD → CNY` 汇率，余额、累计充值、今日实扣、本轮额度与会话累计都按同一口径换算。
- 偏好新增 `displayCurrency`：`auto` / `USD` / `CNY`。`auto` 在新站且汇率可用时显示人民币，旧站自动回退美元。
- 卡片内提供 USD / CNY 两段滑块；设置面板提供「自动 / USD / CNY」三态。旧站没有汇率接口，CNY 入口禁用并说明「钱包以美元记账」。
- 汇率 `status: "stale"` 时仍展示，但状态行用琥珀色提示汇率过期；没有汇率不猜数字，回退美元。
- 人民币是**展示折算**，钱包仍以 USD 记账，插件不会写回或改动余额。

## 余额卡片

- 可用余额标签旁增加币种滑块，CNY 时显示「可用余额 · 折合」，并常显 `1 USD = x.xxxx CNY` 汇率行。
- 切换币种时数字滚动、货币符号轻抬；金额位数多时自动缩小字号。
- CNY 下成本小数位按展示值收敛，避免出现 `¥2.8338` 这类过长金额；隐私模式仍只隐藏余额。
- 深色模式、减少动态效果、设置页字号与账号切换选中态一并调整。

## 浏览器登录态

- Chromium 系新增：Edge Beta / Dev / Canary / WebView2、Chrome 多通道、Chromium、Brave、Vivaldi、Arc、Yandex、Opera / Opera GX、360 极速 / 安全、QQ 浏览器、搜狗浏览器、Maxthon。
- Firefox 系新增：Firefox、Waterfox、LibreWolf、Zen。直接扫描 `Profiles/*/storage/default|permanent/<origin>/ls/data.sqlite`，按 origin 目录判定新旧站，避免串号。
- 保留过期 access token 与同源 refresh token 的配对恢复路径，减少「隔一两天就要重新登录」。

## 验证

- `npm test` 全绿：smoke 30、凭据 13、浏览器 18、币种 9、API 切换 13、UI 77、Cloudflare 10。
- 性能：挂载中位数实测 84–108ms（预算 120ms），单次更新 1.0–1.5ms，新增 DOM 节点 0。
- 真实 Chromium 1440×900 验收 CNY / USD / 设置 / stale / dark 五种状态，字号与对比度 lint 零提示。
