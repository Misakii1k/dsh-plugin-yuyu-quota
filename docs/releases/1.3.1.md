# v1.3.1

## 修复：双站点身份与续期链路的隐患

- **续期落盘错位**：`doRefresh` 写回凭据时曾把账号键 `<site>:<email>` 当成 `email`，而写盘回调按裸邮箱匹配，导致续期成功但新的 refresh token 静默丢失。现统一写回裸邮箱 + 原站点。
- **切号 / 删除跨站歧义**：客户端切号只发裸邮箱，服务端优先 `email`，同邮箱旧站/新站会切错。现在 `/switch` 优先完整 `key`，兼容 `{site,email}`；`/remove` 按 `key` 精确删除，找不到返回 404，切走当前账号时同步 token / site / baseUrl。
- **显式站点 key 不再跨站兜底**：`www:a@x` 不存在时不会回落成 `sub:a@x`；历史裸邮箱仍保留同邮箱兼容。
- **站点解析错误**：`normalizeSiteId('www.anzhiyu.com')` 曾先抹 `www.` 误判成旧站；重写 host / URL / 别名解析，`www.anzhiyu.com` 与裸 `anzhiyu.com` 固定归新站。
- **预热漏账号**：启动预热曾传裸邮箱，导致 www 账号永不预热、同邮箱旧站被重复刷新；改为按 `<site>:<email>` 键预热。
- **过期 token 恢复死代码**：扫描只把未过期 token 放进命中列表，过期恢复函数永远拿不到过期 token 与同源 refresh token。现单独留档过期命中，并只在「无有效激活账号」或用户显式强制同步时切号。
- **自愈迁移重复键**：旧账号被探测到真实站点后，若目标站点已有同邮箱账号，先合并 refresh token、去重，再迁移 activeEmail。
- **历史重复账号自动收敛**：1.3.0 迁移可能在同一 `<site>:<email>` 留下多条记录，加载账号库时按凭据新鲜度与余额同步时间合并为一条，避免切号/删除命中错误副本。
- **自定义 baseUrl 回归**：双站点改造后 `store.baseUrl` 曾变成死配置；认不出的自定义地址仍作为旧站兜底，官方域名按账号站点走。
- **前端切号失败回滚**：本地乐观切号在后端 404 / 不可达时会停在并不存在的账号上；现在完整还原余额、站点、账号指针与激活标记。

## 新增：等待选择通知

- 权限审批（`approval/asked`）、问答选项（`ask_user_question` / `request_user_input`）、计划确认（`exit_plan_mode`）弹出时发系统通知，避免用户离开电脑后 Agent 一直卡在等待。
- 通知标题「等待你的选择 · 会话名」，正文包含操作、会话与原因；同一请求 ID 去重，异常绝不冒泡进 DSH 事件流。
- 设置页新增「等待选择时通知」开关（`notifyOnUserPrompt`，默认开），受通知模式与子 Agent 静默策略控制。

## 新增：余额显示 / 隐藏

- 卡片余额旁新增眼睛按钮；设置页新增「显示余额」开关（`hideBalance`，默认关），两处状态双向同步并持久化。
- 隐藏后余额、累计充值、账号 tooltip、React 设置页金额全部显示 `••••`，并隐藏 `$` 前缀；成本、Token 用量不受影响。
- 任务完成通知里的「当前余额」改为「当前余额 已隐藏」。

## 界面与文档

- 账号徽标由 `sub` / `www` 改为「旧」/「新」，同一邮箱在两站一眼可分。
- 账号胶囊指纹不再包含余额，避免每 30 秒重建整排节点；余额只更新 tooltip。
- README 与 `tutorial.html` 同步双站点、等待选择通知、余额隐私说明。
- 回归测试新增：账号键续期落盘、显式站点解析、过期 token + rt 恢复、等待选择通知、余额显示/隐藏、偏好白名单。
