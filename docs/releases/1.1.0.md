# v1.1.0

## 新增：任务完成通知

每一轮对话结束时，Windows 会弹出系统原生通知，并播放 Windows 官方提醒音。
标题写明是哪个会话完成，正文直接给出这一轮花了多少 Token、折合多少额度。

- 子智能体跑完不会刷屏：默认只提示主会话，它们的用量照样记账。
- 失败或中断的轮次会单独标明，不再混在「完成」里。
- 点一下通知，DSH 窗口会被叫到前台。
- 通知音可换：Windows 提醒 / 默认 / 即时消息 / 邮件 / 短信，或者静音。
- 声音可先试听，设置里有「测试通知」按钮。

## 新增：本轮用量汇报

浮窗卡片多了一块「本轮用量」：本轮 Token 数、实扣额度、会话累计。
卡片收起时，胶囊右上角会出现一个小圆点，点开就能看到。

额度直接从鱼鱼网关 deduction 前后差额算出；万一本轮刷新失败，
会明确写「待同步」，不会拿估算值冒充真实值。

## 新增：浮窗可拖动、自动贴边

按住胶囊就能拖到屏幕任意位置，松手自动吸附最近的边缘；
位置会记住，下次打开还在原处。贴到左边时弹窗自动朝右展开，不会跑出屏幕。
窗口缩小后浮窗也会自己挪回可视区。

## 新增：云端版本推送

插件会自己去云端查有没有新版本。发现新版时胶囊亮红点，设置里能看到
版本号和更新说明，点一下就能下载，下载完自动校验完整性。

云端通道走 GitHub Releases + Cloudflare 边缘代理，仓库保持私有也能用。
部署方法见 `docs/CLOUDFLARE-部署指南.md`。

## 修正

- 「今日用量」里的 Token 统计不再把推理 Token 重复计入（此前会略偏高）。
- 插件设置改为白名单写入，任何非法字段都不会被写进配置文件。
