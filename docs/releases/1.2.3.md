# v1.2.3

## 新增：后台自动静默检测新版本与红点提醒

- **全自动后台轮询**：插件启动后自动进行静默版本探测，后台每隔 6 小时自动检测一次，每次展开卡片时同步静默刷新更新状态，无需手动反复点击。
- **多级联动红点角标**：
  - 展开卡片右上角的齿轮设置按钮（`#yuyu-card-settings-btn`）右上角显示精致呼吸红点；
  - 设置面板内部的【检查更新/下载更新】（`#yuyu-update-check`）按钮右上角同步显示红点；
  - 外部小鲸鱼/胶囊保持干净整洁，仅在卡片与设置层进行精准提醒。
- **常驻提醒与自动消除**：新版本未更新前红点始终常驻提醒，下载安装完成并就绪后自动清除红点。

## 优化：设置界面精简

- **移除冗余立绘单选项**：立绘已专一收敛为经典款，彻底移除了设置面板中多余的“立绘”整行下拉框，设置视图更加简洁紧凑。
