# v1.2.1

## 新增：小鲸鱼立绘与极简胶囊双形态

- **小鲸鱼立绘挂件**：引入活泼灵动的小鲸鱼挂件形态，内置交互式大对话泡泡、点击触发金币下落与摸摸头动画，支持多种立绘造型切换。
- **双形态自由切换**：支持极简胶囊与小鲸鱼立绘自由切换，双击即可无缝切换，偏好自动保存。
- **现代化视觉重构**：设置视图全新采用清晰两栏布局，支持完整暗色模式，卡片与挂件过渡更丝滑。

## 新增：凭据自动续期（免频繁重新登录）

- **自动无感续期**：提取并保存网页端 `refresh_token`，在 token 过期前 5 分钟自动换发新令牌，彻底告别 1~2 天后 401 需重新登录的痛点。
- **并发锁与原子写盘**：解决 refresh token 一次性失效风险，采用串行排队刷新与原子写盘，确保高并发与意外崩溃不丢凭据。
- **凭据健康度显示**：设置面板与卡片底部新增凭据状态及剩余有效时长提示，支持一键手动刷新与故障诊断。

## 增强：多浏览器与 Edge 深度适配

- 深度覆盖 Edge（含 Beta / Dev / Canary 以及 WebView2 / EBWebView 嵌套布局）、Chrome、Brave、Vivaldi、Opera。
- 支持多 Profile 级联探测与诊断信息上报，精准提示扫描状态。

## 安全与稳定性加固

- **桥接端口安全边界**：引入严格的本地 Origin 白名单校验与防跨域 CSRF 保护，拦截非授权来源。
- **路径穿越与 Zip-Slip 防御**：强化本地静态资源与更新安装包解压安全校验。
- **宿主进程防崩溃保护**：畸形请求、空资源与流式异常全面捕获，杜绝意外打崩 DSH 宿主。
