# v1.3.3

在 1.3.2 基础上新增「对话 API 一键对齐」，并合入最后一项余额隐私小修：

- **卡片底部「API」按钮**：按当前账号站点切换 DSH 当前对话的模型供应商。旧站 `sub` → `fish`，新站 `www` → `yuyu`。
- **直接复用 DSH 自带模型选择**：前端读取 DSH 的 `session.modelCatalog`，调用 `session.selectModel`，不新增供应商配置、不写 API Key；当前对话立即生效，DSH 会自行保存为后续默认。
- **当前 sessionId 自动跟随**：通过会话头部的隐形插槽记录，切换对话时同步更新，不会拿上一个会话的 id。
- **失败不落盘**：DSH 模型目录里找不到对应供应商时只提示错误，不改当前模型，也不写任何设置。
- **推理强度尽量保留**：目标模型支持当前 `reasoningEffort` 时沿用（如 `max`），不支持则使用模型自己的默认档位。
- **余额低额红色隐私补丁**：余额隐藏时不再因低额而变红，避免颜色泄露余额状态。
- **子 Agent 同步放开**：desktop profile 的 `subagent-model-selection-settings.allowedModels` 增加 `yuyu`，与 `fish` 并列，避免主会话切到新站后子 Agent 仍走旧站。
