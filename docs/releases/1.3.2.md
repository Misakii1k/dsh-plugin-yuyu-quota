# v1.3.2

在 1.3.1 的基础上补一项线上数据修复：

- **历史重复账号自动收敛**：1.3.0 的自愈迁移在目标站点已有同邮箱账号时会留下重复的 `<site>:<email>` 记录。加载账号库时按凭据新鲜度（`refreshedAt`）与余额同步时间（`lastSyncedAt`）合并为一条，保留较新的 token / refresh token 与较新的余额快照；旧站与新站的同邮箱账号仍然各保留一条。
- 线上 `~/.dsh/yuyu-accounts.json` 已用只读副本验证：3 条重复新站记录 + 1 条旧站记录会收敛为 2 条，不改动原文件；插件重启后自动写回干净结构。
