# v1.2.2

## 修复：任务完成与按压音效推送一致性

- **音频与推送严格一致**：彻底解决设置面板中试听、按压与实际 Windows 原生桌面推送声音不一致的问题。系统推送时原生静音并同步伴随播放用户选中的本地音频（`task-end-a`、`minecraft-exp-orb`、`cost-default`、`duck`、`fx1` 等），告别 Windows 默认系统叮咚音强占。
- **独立试听按钮与通知测试**：
  - “完成音”右侧设置独立【试听】按钮，即时预览所选音频；
  - “按压音”右侧设置独立【试听】按钮，可试听小黄鸭与咚咚声；
  - 增加独立【测试通知】入口，明确推送测试功能。
- **发声防重优化**：开启系统+应用内（both）模式时，避免桌面弹窗发声后前端网页滞后重复播放造成双响。

## 新增：极简胶囊自动贴边吸附

- **智能边缘吸附**：胶囊形态下拖拽松手后，自动根据屏幕中线位置平滑吸附到最近的屏幕边缘（左边缘或右边缘），不再悬浮停留在屏幕中间阻挡视线与内容。
- **形态切换自动对齐**：从小鲸鱼形态切换为胶囊形态时，自动检测并平滑靠边对齐。

## 修复：充值中心跳转页面

- **修正跳转目标**：点击卡片内“充值”按钮以及“累计充值”链接，跳转地址精确修正为 `https://sub.anzhiyu.com/recharge-center`。

## 优化：立绘精简

- **聚焦经典**：挂件立绘精简为专一经典款（DS娘 · 经典，`DSniang1`），移除机甲与深蓝等冗余选项，界面更清爽纯粹。
