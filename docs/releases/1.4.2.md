# v1.4.2

新增「静默补扫」：打开面板或设置页时自动补扫本机浏览器登录态，只把新账号补进账号库，不自动切换当前账号。

## 改动

- 打开余额面板、进入设置页时自动触发浏览器补扫，无需再手动点「从浏览器同步」。
- 静默补扫只新增/更新账号与 refresh token，已有激活账号时不会替你切号；只有账号库为空时才自动选一个。
- 前端 60 秒节流，反复开合面板不会重复扫描；扫描失败也不影响当前余额展示，不会把界面标记为离线。
- 新增 `GET /snapshot?syncBrowser=silent` 后端模式，与手动同步 `syncBrowser=1` 分离。
- 首次挂载、设置页挂载也改为静默补扫，避免打开面板时意外切号。

## 验证

- `scripts/ui-test.mjs` 新增 3 项断言：首次挂载使用静默补扫、打开面板不自动切号、短时间重复打开不重复扫描；UI 测试 80 项全通过。
- `npm test` 全量通过：smoke 30、凭据 13、浏览器 18、币种 9、更新 3、API 切换 13、UI 80、Cloudflare 10，性能在预算内。
