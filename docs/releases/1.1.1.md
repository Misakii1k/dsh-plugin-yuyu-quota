# v1.1.1

## 新增：页面内下载进度条与自动安装

点击「下载更新」后，设置面板内直接展开原生进度条，实时显示下载进度百分比与已下载字节数。
下载完成后自动通过完整性强校验并解压安装到 DSH 运行目录，无需手动敲命令行。

## 新增：Agent 运行态冲突检测

在准备更新和安装过程中，智能检测当前是否有 Agent 正在运行任务：
- 若检测到任务运行中，醒目提示并在安装后提醒用户在任务完成后重启 DSH 生效；
- 若无任务运行，安装完成后直接提示重启 DSH 即可完整生效。

## 优化：更新状态文案与界面极简化

- 前端彻底隐藏更新源输入框，内置官方 Cloudflare 边缘极速通道。
- 更新状态文字优化为「您当前已是最新版本」与「检测到最新版本 vX.Y.Z，可下载更新」，状态更直观友好。
