# v1.2.4

## 修复与优化：UI/UX 体验深度打磨

### 1. 视口边界自适应翻转
- **解决上半屏展开出界问题**：新增动态视口监测机制，当挂件被拖拽至屏幕上半区或窗口高度受限时，卡片自动切换为向下展开模式，避免展开设置视图时顶部 `< 设置` 返回按钮及账号状态被顶出浏览器视口外部。

### 2. 用量指标次序规整与轻量分组
- **次序归一（金额优先）**：将本轮指标调整为「本轮实扣 → 本轮 Tokens」，与全天「今日实扣 → 今日 Tokens」形成一致的阅读动线。
- **视觉分组**：在今日累计与本轮单次会话之间增加微细发丝虚线与舒适边距，降低扫视认知负荷。

### 3. 状态文案语病消除与责任解耦
- **页眉回归健康度指示**：顶栏连接点统一显示语义状态（`就绪` / `离线` / `凭据过期`），不再塞进冗长的时间戳。
- **页脚时间表达自然化**：未同步时自然显示 `3 个密钥 · 未同步 · v1.2.4`，消除旧版首次加载时 `"尚未获取 同步"` 的拼接语病。

### 4. 消除双齿轮视觉冲突
- **外部悬浮齿轮自动隐藏**：在卡片展开状态下，小鲸鱼头顶的悬浮菜单齿轮自动淡出缩放隐藏，避免与卡片内部齿轮产生注意力竞争。

### 5. 胶囊形态异常感知
- **静默状态点**：胶囊钱包图标右上角新增微型状态点，当后端离线或凭据失效时自动点亮，无需展开卡片即可一秒获知连接状态。

### 6. 单账号页眉降噪
- **去除冗余标签**：当本地仅登录单个账号时，自动隐藏顶栏重复的首字母 Chip，保持页眉呼吸感。

### 7. 全新重构新手教程页面
- **设计语言全面对齐**：重构 `tutorial.html`，彻底摒弃旧版三层嵌套卡片与亮蓝高饱和度风格，对齐插件沉静纸面+墨色+发丝线的高质感设计系统，正文字号提升至 13.5px~14px，提供极佳的可读性。
